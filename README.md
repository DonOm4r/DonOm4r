### 🚀 Proyectos Destacados

#### AI Document Assistant (Sistema RAG)
**Stack:** `Python` · `LangChain` · `Pinecone` · `Supabase` · `Streamlit`

Agente conversacional basado en LLMs capaz de responder preguntas utilizando documentos PDF y CSV. Cuenta con pipelines de procesamiento documental, recuperación contextual vectorial y una interfaz interactiva para cargas y consultas.

#### MIDAS (Medición de Impacto de Campañas)
**Stack:** `Python` · `Pandas` · `Forecasting`

Modelo analítico para estimar el impacto de campañas promocionales. Integra datos transaccionales y costos operativos, utilizando modelos de suavizamiento exponencial para comparar ventas reales vs estimadas y evaluar el ROI.

#### MCD (Certificación y Validación de Datos)
**Stack:** `Python` · `Streamlit` · `Pandas` · `JSON`

Aplicación interna con arquitectura modular para validación de datos en pipelines analíticos. Automatiza limpieza de inconsistencias y presenta dashboards con KPIs sobre tiempos de procesamiento y errores corregidos.
